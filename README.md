### 🎯 Descripción

"Arma la Frase" es un juego educativo web diseñado específicamente para niños con discapacidad auditiva. Los niños aprenden a construir frases correctamente arrastrando fichas de palabras a su posición adecuada, con **feedback 100% visual** a través de una mascota animada.

---

## ✨ Características de Accesibilidad

### 🌟 Cumplimiento WCAG 2.2 Nivel AA (100%)

- ✅ **Navegación completa por teclado** - No requiere mouse
- ✅ **Contraste de color 4.5:1+** - Legible para baja visión
- ✅ **Foco visible** - Indicadores claros de 3-4px
- ✅ **ARIA labels completos** - Compatible con lectores de pantalla
- ✅ **HTML semántico** - Estructura clara para tecnologías asistivas
- ✅ **Diseño responsivo** - Funciona en móviles, tablets y desktop

### 🎮 Características de Usabilidad

- ✅ **Doble entrada:** Mouse + Teclado
- ✅ **Mascota siempre visible** - Feedback visual constante
- ✅ **Prevención de errores** - Botón "Verificar" bloqueado hasta completar
- ✅ **Botón Home persistente** - Salida fácil desde cualquier pantalla
- ✅ **Atajos de teclado globales** - Navegación rápida (Alt+tecla)

---

## ⌨️ Atajos de Teclado

| Atajo           | Acción               |
| --------------- | -------------------- |
| `Alt+I`         | Ir a Inicio          |
| `Alt+J`         | Ir a Jugar           |
| `Alt+R`         | Ir a Premios         |
| `Alt+A`         | Ir a Ajustes         |
| `Alt+H`         | Ver Tutorial         |
| `Ctrl+V`        | Verificar respuesta  |
| `Ctrl+R`        | Reiniciar nivel      |
| `Ctrl+P`        | Solicitar pista      |
| `↑↓←→`          | Navegar entre fichas |
| `Enter/Espacio` | Seleccionar ficha    |
| `Esc`           | Cerrar modales       |
